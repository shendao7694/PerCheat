# PerCheat
> 警告：这是一个Box3作弊程序的开源代码，本程序可使用的Box3平台已经关服，因此开源PerCheat代码

## 快速开始
构建源代码：
`npm run build`

开启开发栈：
`npm run dev`

## 项目结构
`src/i18n`  i18n 多语言 主程序

`src/main` 核心程序目录

`src/main/GameCore` PerCheat的核心，用于抓取Box3实例

`src/main/GameFront` PerCheat的一些前置

`src/main/GameGUI` PerCheat的UI

`src/main/GameModules` PerCheat中所有作弊模块的程序

`src/sys` 支持库程序
